# 面向需求分析师的会话记忆系统 - 需求规范

## 功能概述
开发一个面向需求分析师的会话记忆系统，支持多轮对话、需求抽取、上下文管理。

## 核心需求
1. 支持创建多个会话，每个会话独立维护消息历史
2. 每次对话自动保存用户消息和AI回复到数据库
3. 支持上传需求文档（MD/PDF/DOCX），自动解析并向量化存储
4. 分析需求时，自动检索相关文档片段作为上下文增强分析
5. 多Agent协作：抽取Agent、澄清Agent、分析Agent、风险Agent、汇总Agent
6. 支持SSE实时推送任务进度
7. 任务事件持久化，离线后可查询历史

## 非功能性需求
- 消息持久化到PostgreSQL，重启后历史不丢失
- Embedding模型本地运行，无需外部API
- pgvector实现余弦相似度语义检索
- 用户隔离：每个用户只能检索自己的文档

## 约束条件
- 单次输入不超过2000字符
- 文档上传大小限制10MB
- Embedding模型维度384
- 分块大小500字符，重叠50字符
